# Security Policy

## Supported Versions

We provide security updates for the following versions of the project:

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability in this project, please **do not open a public Issue**. 

Instead, report it privately by sending an email to:
**novakvova@gmail.com**

I aim to respond to security reports within 48 hours and resolve critical issues as quickly as possible. Thank you for helping keep this project secure!
